# DistanceUprav ⚡

## Обновление: Android 0.4.1 + Windows Agent 0.4.2

- Windows-агент делает снимок видимых окон каждые 2 секунды. Через защищённый API `/v1/apps` отдаёт **открытые окна** и **историю недавно закрытых** с отметками времени (последние 20 событий закрытия, только с момента запуска агента).
- В Android карточка Windows Agent автоматически обновляет список раз в 5 секунд, пока приложение открыто. Показываются разделы **«Открытые окна Windows»** и **«Недавно закрытые окна»**, ручное обновление остаётся доступным.
- Предупреждение о риске несохранённых изменений и подтверждения закрытия/выключения/перезапуска теперь оформлены в фирменном тёмном стиле DistanceUprav.
- Агент определяет, запущено ли окно с повышенными правами, и сообщает об ограничении **Windows UAC**. Обычный агент не должен и не может обходить UAC ради закрытия консоли администратора. При необходимости пользователь может **вручную** запустить Windows Agent от администратора на ПК, подтвердив UAC, но это повышает права удалённого управления — запускать так постоянно не рекомендуется, даже в домашней сети.
- Закрытие по-прежнему **мягкое (WM_CLOSE)**. Фраза «Запрос закрытия отправлен» не означает, что приложение действительно закрылось: отсутствие окна будет видно при следующем обновлении. Если приложение спрашивает о сохранении документа, решение принимается на ПК.
- Подпись Android, идентификатор приложения и Wake-on-LAN не менялись. Android v0.4.1 (`versionCode 9`) устанавливается поверх v0.4.0 (`versionCode 8`), Windows Agent v0.4.2 заменяет предыдущий EXE, конфигурация агента сохраняется.


## Исправление подключения — Windows Agent v0.4.1

Если телефон показывает ошибку подключения к адресу `172.19.0.1:8765` при том, что сам телефон имеет IPv4 `192.168.0.36`, то Windows-агент выбрал виртуальный интерфейс (часто WSL/Docker/Hyper-V). Начиная с v0.4.1 агент предпочитает физические Ethernet/Wi-Fi интерфейсы с маршрутом по умолчанию, показывает список сетевых адаптеров и позволяет **вручную выбрать IPv4 ПК**.

1. На ПК запусти обновлённый Windows-агент v0.4.1.
2. Выбери в списке IP домашнего ПК, например `192.168.0.105`, а не `172.19.0.1`. Если нужного адреса нет, посмотри `ipconfig` и введи его вручную.
3. После изменения IP агент создаст новый QR-код. На Android в карточке Windows Agent снова выбери «Подключить Windows-агент по QR». **Установленный Android APK менять не нужно.**
4. Если IP правильный, но соединения всё равно нет, проверь правило Windows Defender Firewall для **TCP 8765**, профиль **Private**, `RemoteAddress LocalSubnet`. Не пробрасывай порт в интернет.

При смене IP ключ сертификата и секретный токен сохраняются: данные находятся в `%LOCALAPPDATA%\DistanceUpravAgent`.


## v0.4.0 — Windows Agent

Android по-прежнему включает ПК через Wake-on-LAN без Windows-агента. Прежние настройки MAC/IP, UDP 9, приложение и постоянная тестовая подпись APK сохранены.

Новый агент Windows 10/11 позволяет просматривать открытые окна приложений, выборочно запрашивать закрытие окна, выключать и перезагружать компьютер. На телефоне каждое опасное действие требует подтверждения.

### Как подключиться

1. В GitHub Actions открой успешную сборку Build Windows Agent и скачай артефакт DistanceUprav-Windows-Agent.
2. Извлеки DistanceUpravAgent.exe и запусти его в обычном пользовательском сеансе Windows (не как службу).
3. Разреши входящие подключения на порт TCP 8765 **только для частной домашней сети**. Из PowerShell с правами администратора:

    New-NetFirewallRule -DisplayName "DistanceUprav Agent (Private LAN)" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8765 -Profile Private -RemoteAddress LocalSubnet

4. Установи APK 0.4.0 поверх 0.3.0. В карточке Windows Agent выбери подключение по QR и отсканируй QR с экрана ПК.
5. Нажми «Обновить список программ», затем используй кнопки закрытия конкретных окон или управления питанием.

### Сохранение файлов — важное ограничение

Универсального способа автоматически сохранять все несохранённые документы во всех программах Windows нет. Агент отправляет обычный WM_CLOSE и НЕ использует taskkill / TerminateProcess. Приложение может показать диалог «Сохранить?» на самом ПК. Если сохранение требует подтверждения, его нужно выполнить на ПК; закрытие может не завершиться до этого.

Выключение и перезагрузка запускаются без принудительного закрытия программ. Перед командой есть 10-секундная задержка и кнопка отмены. Используются команды shutdown.exe /s /t 0 и /r /t 0 **без /f**. Windows может блокировать действие, если есть несохранённые данные. Сохранение не гарантируется.

### Безопасность

- TLS HTTPS со своим сертификатом; Android проверяет сертификат по отпечатку SHA-256 в процессе TLS до передачи токена.
- Случайный токен привязки передаётся QR-кодом с экрана самого ПК, хранится на телефоне через Android Keystore.
- Агент ограничивает подключения локальной сетью и требует токен для всех операций.
- НИКОГДА не открывай порт 8765 наружу через интернет. При необходимости в будущем используем защищённый VPN.
- Секретные файлы лежат в %LOCALAPPDATA%\DistanceUpravAgent. Не выкладывай их и не делись QR-кодом.
- Android debug APK подписываются стабильным, но публичным тестовым ключом; для реального релиза нужен приватный ключ.

### Сборки

- Android GitHub Actions: .github/workflows/android.yml → DistanceUprav-debug-apk.
- Windows GitHub Actions: .github/workflows/windows-agent.yml → DistanceUprav-Windows-Agent.
- Версия Android: 0.4.0, versionCode 8. Настройки и подпись предыдущей версии сохранены.

### Wake-on-LAN

Для включения ПК нужен MAC Ethernet-адаптера. IPv4 требуется только для проверки статуса. ПК должен быть настроен для Wake-on-LAN в BIOS/UEFI, Windows и сети. Отсутствие ping-ответа не доказывает выключение.
