# DistanceUprav ⚡

Android-приложение для включения одного ПК через домашнюю сеть. Отдельный проект от SofaPower.

## 0.2.1 — ручное подключение как в старом SofaPower
Основной сценарий не требует QR-кодов, Windows Hub или портов TCP:
1. Подключи телефон по Wi-Fi к домашнему роутеру и компьютер к тому же роутеру (желательно по Ethernet).
2. Введи физический MAC-адрес Ethernet-адаптера компьютера. Его можно найти командой `ipconfig /all` в Windows.
3. Нажми «Сохранить настройки», затем «Включить компьютер».
4. Приложение определит сетевой broadcast адрес через `ConnectivityManager` / `LinkProperties`, сформирует WoL Magic Packet и трижды отправит его по UDP на порт 9.

Для включения **достаточно MAC**. Локальный IPv4 компьютера вводится только для кнопки «Проверить доступность» и автоматического статуса. Статус определяется через ICMP ping с резервной проверкой `InetAddress.isReachable`. Если Windows блокирует ICMP или устройство недоступно, отрицательный статус **не доказывает**, что ПК выключен.

## Дополнительно
Внизу экрана оставлена необязательная QR-привязка из более нового SofaPower Hub (формат `sofapower://pair?data=...`). На старой версии SofaPower она не нужна. Сканирование работает через Google Code Scanner при наличии соответствующих сервисов на телефоне; MAC/IP также можно ввести вручную, а MAC — вставить из буфера.

## Требования
Wake-on-LAN должен поддерживаться сетевой картой, быть включён в BIOS/UEFI и настройках Windows, а адаптер должен получать дежурное питание. Из интернета (вне домашней сети) функция не работает без дополнительной инфраструктуры.
