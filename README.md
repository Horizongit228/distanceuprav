# DistanceUprav ⚡

Новый Android-проект управления одним домашним ПК. Отдельный проект, не связанный с SofaPower.

Первая версия: Wake-on-LAN, диагностика сети, проверка доступности по TCP, локальные настройки и сборка APK в GitHub Actions.

> Включение по Wake-on-LAN требует поддержки со стороны ПК и обычно работает в одной локальной сети. Управление через интернет потребует настроенного VPN или безопасного ретранслятора.
