# DistanceUprav ⚡
Android-приложение для управления одним ПК по локальной сети. Самостоятельный проект, **SofaPower не изменяется**.

## Версия 0.2.0 — подключение по технологии SofaPower
- Совместимость с QR из **SofaPower Hub для Windows** (`sofapower://pair?data=...`): считываются имя ПК, MAC Ethernet и локальный IPv4.
- QR-сканер Google Code Scanner (на устройствах с Google Play Services). Камера обрабатывается сервисом сканирования; приложению не требуется разрешение CAMERA.
- Если сканер не работает, код связи можно вставить из буфера обмена или ввести MAC/IP вручную.
- Wake-on-LAN из исходного `WolUtils.java` SofaPower: определение локального IPv4 и широковещательного адреса через `ConnectivityManager`/`LinkProperties`, 3 UDP Magic Packet на порт 9.
- Проверка состояния как в SofaPower: ping с резервной проверкой `InetAddress.isReachable(900)`; обновление состояния каждые 20 секунд, повторные проверки после включения.
- **Нет необходимости открывать RDP-порт 3389 или устанавливать TCP-сервис на Windows.**

## Подключение
1. Запусти SofaPower Hub на компьютере, выбери Ethernet-адаптер и покажи QR.
2. Подключи Android и ПК к одному домашнему роутеру (ПК желательно по Ethernet).
3. В DistanceUprav нажми «Сканировать QR SofaPower Hub» и считай код; или вставь скопированный код. Если Hub недоступен, введи MAC/IP вручную и сохрани.
4. Используй «Проверить доступность» для проверки онлайн-статуса и «Включить компьютер» для отправки Wake-on-LAN.

*QR-связка не означает постоянного соединения и не запускает сервер на ПК. Hub нужен для передачи настроек и диагностики WoL. ICMP может блокироваться брандмауэром Windows: отсутствие ответа не доказывает, что компьютер выключен. Для включения ПК нужна поддержка Wake-on-LAN и питание Ethernet-адаптера. Приложение пока предназначено для домашней сети, а не прямого подключения через интернет.*
