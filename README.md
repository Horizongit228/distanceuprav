- Тёмная панель управления с карточкой ПК, крупной круглой кнопкой **«Включить ПК»**, заметным индикатором статуса и диагностикой локальной сети.
- Настройки MAC и IPv4 сворачиваются после сохранения. MAC остаётся достаточным для Wake-on-LAN; IPv4 нужен только для проверки состояния.
- Действия: обновить информацию о сети, проверить доступность, вставить MAC из буфера, QR-привязка к новому SofaPower Hub (как необязательный раздел).
- Используются прежние настройки `mac`/`host`, тот же `WolUtils.java`, три Magic Packet по UDP 9, ping и резервная проверка `isReachable`.
- **Установка поверх 0.2.2:** `applicationId` прежний, `versionCode` увеличен с 6 до 7, используемый GitHub Actions постоянный отладочный ключ оставлен без изменений.
- Показатель «ПК не отвечает» не означает достоверного выключения компьютера: ICMP может блокироваться.
- Обновление интерфейса не включает управление сном/выключением Windows — для этого в будущем потребуется отдельный защищённый агент.


## Исправление обновлений — v0.2.2
Начиная с v0.2.2 GitHub Actions подписывает все тестовые APK **одним и тем же debug-ключом**, вместо временного ключа нового runner при каждой сборке.

⚠️ **Переход с v0.2.1 и более ранних версий:** старые версии подписаны разными временными ключами. Сначала запиши MAC и IP компьютера, удали старую DistanceUprav, затем установи v0.2.2. Настройки старой установки при удалении сбрасываются. После этого следующие debug APK (с тем же applicationId и debug-ключом) должны устанавливаться как обновления поверх v0.2.2.

`app/debug-signing.keystore.b64` — **публичный ключ отладки** с общедоступным паролем; НЕ использовать для production, публикации в Google Play, безопасных каналов обновления или хранения секретов. Для будущих release-сборок потребуются собственный закрытый ключ в GitHub Actions Secrets и отдельная политика обновления. CI распаковывает временный `app/debug.keystore`, который не попадает в git.


Android-приложение для включения одного ПК через домашнюю сеть. Отдельный проект от SofaPower.

## 0.2.1 — ручное подключение как в старом SofaPower
Основной сценарий не требует QR-кодов, Windows Hub или портов TCP:
1. Подключи телефон по Wi-Fi к домашнему роутеру и компьютер к тому же роутеру (желательно по Ethernet).
2. Введи физический MAC-адрес Ethernet-адаптера компьютера. Его можно найти командой `ipconfig /all` в Windows.
3. Нажми «Сохранить настройки», затем «Включить компьютер».
4. Приложение определит сетевой broadcast адрес через `ConnectivityManager` / `LinkProperties`, сформирует WoL Magic Packet и трижды отправит его по UDP на порт 9.

Для включения **достаточно MAC**. Локальный IPv4 компьютера вводится только для кнопки «Проверить доступность» и автоматического статуса. Статус определяется через ICMP ping с резервной проверкой `InetAddress.isReachable`. Если Windows блокирует ICMP или устройство недоступно, отрицательный статус **не доказывает**, что ПК выключен.

## Дополнительно
Внизу экрана оставлена необязательная QR-привязка из более нового SofaPower Hub (формат `sofapower://pair?data=...`). На старой версии SofaPower она не нужна. Сканирование работает через Google Code Scanner при наличии соответствующих сервисов на телефоне; MAC/IP также можно ввести вручную, а MAC — вставить из буфера.

## Требования
Wake-on-LAN должен поддерживаться сетевой картой, быть включён в BIOS/UEFI и настройках Windows, а адаптер должен получать дежурное питание. Из интернета (вне домашней сети) функция не работает без дополнительной инфраструктуры.
